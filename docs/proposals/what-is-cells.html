01 / 11

Cells.

A fleet of AI agents, each in its own little Linux machine.

All running on your Mac.

Pete McCarthy  ·  2026

02 / 11  ·  The idea

Hand it a problem.
It builds the team.

You don't wire up infrastructure or configure cloud services. You describe what needs doing — and a fleet of agents spins up to do it. Each agent in its own machine. The whole fleet on your Mac.

A substrate that turns any business problem into a working fleet of agents.

03 / 11  ·  The unit

A cell is a little Linux machine.

  • One agent insideIts own files, shell, network, memory, identity. A place an agent lives — not a chat session.
  • Any harnesspi, Claude Code, Codex, OpenClaw — whatever you want running the agent.
  • Any modelLocal models on your own silicon, or cloud LLMs. The cell doesn't care. Every cell can run the smartest model you've got.
  • Real isolationActual hardware virtualization. Not a container, not a sandbox-in-a-tab. The machine is the boundary.
  • A real computerYou can hack on it. It can hack on itself. It just works.
04 / 11  ·  Birth

You birth a cell.

$ cells birth
  waking  ━━━━━━━━━━  warming  ━━━━━━━━━━  ready

cell> Hi. I'm new here. What should I call you, and what
       should I call myself?

you> I'm Pete. You can be alice.

alice> Got it, Pete. What are we working on?

Seconds, start to finish. The cell speaks first — every word generated live by an LLM. No canned text, no loading screen pretending to be a personality.

05 / 11  ·  Why local

This only works on your machine.

A cloud VM can't do what a cell does.

  • On the metalApple Silicon, native. Fast in a way a rented cloud instance isn't. This is what the memory in your Mac is for.
  • Hot eject, hot reloadIdle a cell and it leaves memory. Call it back and it's instantly live. The fleet breathes — only what you're using is running.
  • No network taxAgents talk to agents constantly. Over a network, that's latency stacked on latency. On one machine, it's free.

A fleet that lives on one machine doesn't pay the network tax.

06 / 11  ·  The shape

It's a fleet. You can tune any part of it.

A chatbot is one window. A fleet is a structure — a Chief of Staff with cells under it, each owning a piece of the work.

For example

Your Chief of Staff runs marketing. Marketing has a LinkedIn cell. You can drop straight into that LinkedIn cell and tune it — it has its own memory, and being "the LinkedIn cell" doesn't make it dumb. It runs whatever model you point it at.

Every cell in the chain is reachable. Every one is yours to shape.

07 / 11  ·  Always on

Close the lid.
The fleet keeps running.

Cells run locally — but they're not trapped there. Cloudflare marries the local fleet to the network: your agents stay reachable from anywhere, even with your laptop shut.

Designed to live on a Mac Mini or Mac Studio. Plug it in — that's your always-on agent box. The fleet runs all the time; you reach it from wherever you are.

08 / 11  ·  The substrate

Every problem, the same infrastructure.

Open a repo. It carries the skills to design a fleet — the agents, the workflows, the org chart. You're not standing up cloud services; you're describing a company, and watching it spin up.

The infrastructure underneath never changes. Wells is the framework — the thing that makes a little Linux machine appear on demand. Cells is what you talk to.

Different repo, different company. Same substrate. All local.

09 / 11  ·  Today

V1 shipped. Here's what the numbers mean.

  • First word in ~2.5s By the time you've read the prompt, the cell is answering. It doesn't feel like booting a machine — it feels like the agent was always there.
  • Warm birth in 70–100ms Faster than a screen refresh. You don't manage a pool of agents — you birth one when you need it, and it's there.
  • Sleep 0.6s · wake 0.4s Idle cells leave memory and cost nothing. Waking is instant. The fleet breathes — only what you're using is live.
  • Siblings unaffected Kill one cell and the rest don't notice. Real isolation — not shared state pretending to be separate.
